# Daehee Koo — CV

Personal CV website for GitHub Pages.

## Publish
Create a public repository named `DH-Koo.github.io`, upload these files to `main`, then select **Settings → Pages → Deploy from a branch → main → / (root) → Save**.

## Update
Edit `index.html` for website content and replace `CV_DaeheeKoo.pdf` for the downloadable CV.
